# archive/

Tracked home for **textual verbatim originals**: byte-faithful documents worth
keeping whole (founding records, important source texts), each fronted by a thin
`sources/` note that carries provenance and distillation state. **Text only, by
total policy** — binaries go to the gitignored `assets/` binary store. Each entry
is a directory named exactly after its fronting note's stem
(`archive/<yyyy-mm-dd>-<slug>/`), so pairing is mechanical both ways. Not
link-indexed, so literal double-bracket syntax inside archived text cannot break
`graph.py check`. Naming/policy authority: AGENTS.md §Layout.
