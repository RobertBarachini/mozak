  [AGENTS.md](../AGENTS.md) Layout table — while gitignoring both entirely in

  never-read rule absolute. Verified the ignore with `git check-ignore`. This is a
  template-owned change (`.gitignore`, per SYNC's ownership table) plus a shared-evolving
  one (AGENTS.md) — instances inherit both via the `git merge template/main` pull ritual.
